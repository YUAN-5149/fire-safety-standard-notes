# 各類場所消防安全設備設置標準 — 學習筆記

台灣「**各類場所消防安全設備設置標準**」（內政部依消防法第 6 條第 1 項訂定）的結構化學習筆記、**十八套設備計算圖解**與 **815 題互動題庫**。

圖解已涵蓋第三編**第一章「滅火設備」全部八節**（滅火器、室內外消防栓、自動撒水、水霧、泡沫、二氧化碳含惰性氣體、乾粉含簡易自動滅火、鹵化烴）、**第二章「警報設備」全部四節**（火警自動警報、手動報警、緊急廣播、瓦斯漏氣火警自動警報）、**第三章「避難逃生設備」全部三節**（標示設備、避難器具、緊急照明設備）、**第四章「消防搶救上之必要設備」全部五節**——**第三編四章已完整涵蓋**。**第四編「公共危險物品等場所消防設計及消防安全設備」全編（§193～§233）與第五編附則（§234～§239）亦已完整涵蓋**。另有電子工業廠房的**潔淨區消防安全設備設置要點**。

## 六個要留意的法規細節

1. **第四編只到 §233，§234 起已是第五編** — 很多講義（含本筆記舊版總覽）寫成「第四編 §193～§239、第五編 §240」。現行條文的「第 五 編 附則」標題緊接在 §233 之後、§234 之前，且全法最後一條是 **§239（施行日期）**，並無 §240。第四編正確範圍為 **§193～§233**（第一章消防設計 §193～§208、第二章消防安全設備 §209～§233）。

2. **§220 沒有 §76 第 2 項的「＋20%」** — 第三編泡沫水源要「加算充滿配管所需之泡沫水溶液量，**且應加算總泡沫水溶液量之百分之二十**」（§76Ⅱ）；第四編 §220 本文只寫「並加計配管內所需之水溶液量」，**沒有那 20%**。這是兩編之間少數「第四編反而較寬」的地方，容易因習慣而多乘 1.2。另 §222 第 3 項的係數究竟只乘體積項、還是連同 §222Ⅰ② 的開口加算一起乘，條文文義未明；本筆記採實務通行的「係數只乘體積項」，送審前建議確認。

3. **§73 有殘留引用** — 現行 §18 附表只剩一～七項（舊第八項「引擎試驗室、石油試驗室、印刷機房」已刪除），但 §73 高發泡放射量表仍保留「第十八條表第八項之場所」一列。屬修法後未同步更新的引用，實務上已無對應場所。

4. **§76 第 2 項的 20% 加算文義不明確** — 「加算總泡沫水溶液量之百分之二十」中的「總泡沫水溶液量」指哪個量，條文沒有寫死。本筆記全部採實務通行的 `V = (V₀ + V_配管) × 1.2`。送審前建議向當地消防機關確認。

5. **潔淨區要點裡沒有「氣體滅火設備」** — 半導體無塵室怕水、所以用海龍替代品，這是常見誤解。翻遍要點全十一點：潔淨室的滅火主力是**密閉濕式自動撒水設備**（第六點，撒水密度 8.15 L/min·m²）；唯一入法的「氣體」是第四點的**二氧化碳滅火器**（可攜式滅火器，不是固定式氣體滅火設備）；機臺內建的滅火系統依第二點第二項歸**中央目的事業主管機關**管轄，不在要點內。第十點反而是一條「准許把第三種（含 CO₂、惰性氣體、鹵化烴）改為第二種（自動撒水）」的授權。

6. **潔淨區要點有三處「由中央消防主管機關另定」** — 要點給了撒水密度 8.15（第六點Ⅰ②）與排氣導管 1.9（第六點Ⅲ①）兩個數值，卻把「怎麼把密度換算成每個撒水頭的放水量與配置」留給中央消防主管機關另定；第七點Ⅳ④但書的探測器組防護面積也是「認可值」。本筆記採實務通行的「密度 × 單頭防護面積，再與 §50 的 80 L/min 取嚴者」，**這不是要點明文**，送審前務必向當地消防機關確認。
