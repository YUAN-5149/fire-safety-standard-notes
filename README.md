## 特色

- **所有數字均取自現行條文原文核對**，不是憑印象整理
- §18、§57 等條的表格在法規資料庫網頁版被省略（顯示「因條文排版無法完整呈現內容」），本筆記已從各該條的完整條文 PDF 補齊
- 題庫答錯時，解析會**直接連到對應的圖解段落**
- 泡沫設備獨立成計算專章，四條路徑（低發泡固定式／高發泡全區／高發泡局部／移動式）分別給出公式與逐步演算

## 兩個要留意的法規細節

1. **§73 有殘留引用** — 現行 §18 附表只剩一～七項（舊第八項「引擎試驗室、石油試驗室、印刷機房」已刪除），但 §73 高發泡放射量表仍保留「第十八條表第八項之場所」一列。屬修法後未同步更新的引用，實務上已無對應場所。

2. **§76 第 2 項的 20% 加算文義不明確** — 「加算總泡沫水溶液量之百分之二十」中的「總泡沫水溶液量」指哪個量，條文沒有寫死。本筆記全部採實務通行的 `V = (V₀ + V_配管) × 1.2`。送審前建議向當地消防機關確認。
